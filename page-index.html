Supra-Rust 100M

A 100M-parameter base model, further trained on Rust, RFCs, C, math and physics. It runs entirely in your browser: the model (~108 MB) is downloaded once, nothing is sent anywhere. It is a base model: it continues text, it does not answer questions. Start something and let it finish.

    About this model
    
Starting point: Supra2-100M (Qwen3 architecture, 12 layers, 32k vocabulary). Continued pretraining in five
    phases: Rust code + RFCs at 8k context, a 64k-context phase, a mixed phase with Stack Exchange math/physics,
    OpenStax textbooks, fd.io VPP C and more Rust, a short 64k refresh, and a final run that mixes 8k and 64k
    windows (this model). It stays stable over long inputs but
    reliably recalls only roughly the last 8k tokens. Weights here are 8-bit (q8_0) GGUF, run with
    wllama (llama.cpp in WebAssembly). Context in this page: 8192 tokens.
